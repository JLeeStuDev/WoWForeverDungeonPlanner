# WoW Forever Dungeon Run Planner

A single-page planner for running every WoW Forever dungeon once while leveling.

- All 29 dungeons in run order (Scarlet Monastery, Maraudon, Dire Maul and Stratholme count as one run each)
- Enemy level range and best level for each dungeon
- Party planner: enter up to 5 levels and pick a faction to see what's ideal now, what's doable, and where you're losing XP under the 12-level dungeon XP rule
- Check off dungeons as you clear them (saved in your browser)

**Live page:** https://jleestudev.github.io/WoWForeverDungeonPlanner/

Enemy levels for the 9 new Forever dungeons come from Blizzard's announced ranges and recorded boss levels. Levels for the 20 original dungeons are Classic values and may be off by 1–2 in Forever.
